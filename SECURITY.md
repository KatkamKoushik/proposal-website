# Security Policy

## Supported Versions

Only the latest version on the `main` branch currently receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| main    | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please follow these steps:

1. **Do not create a public issue** on GitHub.
2. Send an email to the project maintainer at `koushikkatkam@gmail.com` with the subject line `[SECURITY VULNERABILITY] - Proposal Website`.
3. Include detailed information about the vulnerability:
   * Description of the vulnerability and potential impact.
   * Steps to reproduce the issue or proof-of-concept code.
   * Any recommended remediation steps if known.

### Response Timeline

* Maintainers will acknowledge receipt of the report within 48 hours.
* We will investigate and provide regular status updates until the vulnerability is addressed.
* Once resolved, a patch will be deployed and an announcement will be credited to the reporter (unless anonymity is preferred).
