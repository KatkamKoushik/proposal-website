# Accessibility Statement

We are committed to ensuring digital accessibility for all users, including individuals with disabilities. We continually improve the user experience and apply relevant accessibility standards.

## Conformance Status

This project aims to adhere to the [Web Content Accessibility Guidelines (WCAG) 2.1](https://www.w3.org/WAI/standards-guidelines/wcag/) Level AA standards where applicable.

### Measures Taken to Support Accessibility

* **Semantic HTML:** Utilizing landmark elements and structured semantic elements wherever possible.
* **Color Contrast:** Testing text color against background gradients and particle scenes to ensure legibility.
* **Keyboard Navigation:** Ensuring interactive triggers and controls can be navigated via keyboard focus.
* **Motion Preferences:** Striving to respect the `prefers-reduced-motion` media query for users sensitive to motion animations.
* **Responsive Layouts:** Ensuring scaling and legibility across varying viewport sizes and zoom levels.

## Known Limitations

While we strive for complete accessibility, some decorative background particles and experimental scroll transitions may present limitations:
* Background particle animations are primarily aesthetic and non-essential for narrative comprehension.
* Certain gestures are designed for vertical touch scrolling and mouse wheels.

## Supported Environments

The application is tested on modern web browsers including:
* Google Chrome (latest versions)
* Mozilla Firefox (latest versions)
* Apple Safari (latest versions)
* Microsoft Edge (latest versions)
