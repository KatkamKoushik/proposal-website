# Soft Constellations

> *Somewhere between nightfall & a wish.*

A cinematic, interactive scroll-based storytelling website designed as an immersive digital romantic experience. Built with Next.js 16 (Turbopack), React 19, Framer Motion 14, Lenis Smooth Scroll, and Tailwind CSS.

**[View the Live Experience](https://proposal-website-drab.vercel.app/)**

---

## Features

* **Continuous Fluid Flow:** A seamless, single-canvas vertical scrolling journey powered by Lenis Smooth Scroll, eliminating rigid page breaks.
* **Ambient Celestial Video Backdrops:** Web-optimized H.264 ambient motion backgrounds, featuring a celestial heart-swirl particle loop and an ethereal rose heart tunnel.
* **Astronomical Heart Constellation:** A mathematically mapped celestial heart featuring 18 star vertices, glowing starlight constellation lines, interior star-chart guide lines, rotating 4-point diffraction spikes, and a gentle breathing heartbeat animation.
* **SSR Hydration-Safe Cosmic Stardust:** Deterministic pseudo-random distribution ensuring zero hydration mismatches between server render and client hydration.
* **Celestial Starlight Whisper Cards:** Luxurious frosted-glass memory cards with starlight badges, glowing rose-gold hover states, and poetic typography.
* **Minimalist Celestial Orbital Nexus:** Intersecting elliptical orbit paths with a central sparkling star representing connection and the initial spark.
* **Celestial Wish Section:** An interactive sealed letter and wish-release experience with gentle local heart rainfall and celebratory confetti starbursts.
* **Sensory Soundscape:** Ambient instrumental soundscape with smooth volume fade on user interaction and a persistent floating glassmorphism audio pill.
* **Universal Artistic Experience:** Free from personal names or wedding proposals, crafted as an inspiring and universally admired digital romantic sanctuary.

## Getting Started

Follow these steps to run the project locally with `pnpm`:

### Prerequisites

Ensure you have Node.js 18+ and `pnpm` installed:

```bash
npm install -g pnpm
```

### Installation & Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/KatkamKoushik/proposal-website.git
   cd proposal-website
   ```

2. **Install dependencies:**
   ```bash
   pnpm install
   ```

3. **Start the development server:**
   ```bash
   pnpm dev
   ```

4. **View in browser:**
   Open [http://localhost:3000](http://localhost:3000) to explore the experience.

---

## Building for Production

To create an optimized production build:

```bash
pnpm build
pnpm start
```
